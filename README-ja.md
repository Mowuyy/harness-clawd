## なぜHarnessClawdか

### ビジョン：マルチエージェント、プロダクショングレード、マルチテナント
HarnessClawdは単なるデモではなく、実運用可能なデジタルワークフォースプラットフォームです：

- マルチエージェントオーケストレーション：メインタスク、サブエージェント、協調エージェント、チーム受信箱スケジューリングを標準搭載。
- プロダクショングレードの堅牢性：自動コンテキスト圧縮、タイムアウト/リトライ、拡張可能なツールレジストリ、統合設定レイヤー。
- マルチテナント分離：1つのプラットフォーム上で複数テナントをサポートし、データと設定を分離。

### 由来
- **Claude Code**：Anthropicのプロダクショングレードコーディングエージェント。ツール呼び出しループ、コンテキスト圧縮戦略、薄く監査可能なループ設計を参照。
- **open-clawd**：Claude Codeアーキテクチャのオープン実装。非同期設計、サブエージェント生成、チーム受信箱協調、スキルロード機構を採用し、完全プラグイン式LLMプロバイダ層を追加。

## 機能

- OpenAI、DeepSeek、Ollama、vLLM、Azureなどを切り替え可。
- 直感的なツール呼び出しとサブエージェントワークフロー。
- トークン閾値での自動コンテキスト圧縮。
- チーム協調と非同期メッセージング。
- REPL `/compact` `/tasks` `/team` `/inbox`。
